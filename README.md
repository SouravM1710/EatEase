EatEase

Overview

EatEase is a full-stack restaurant order and pickup management system designed to reduce waiting times and streamline food ordering. Customers can browse restaurant menus, place orders in advance, and pick up their food at the selected time, while restaurant owners can efficiently manage menus, orders, and customer requests through a dedicated dashboard.

The platform focuses on improving customer experience by enabling contactless ordering and helping restaurants manage peak-hour traffic more effectively.

---

Features

Customer

- User registration and login
- Browse restaurant menus
- View food item details
- Add items to cart
- Place orders for pickup
- View order history
- Track order status

Restaurant Admin

- Secure admin login
- Manage menu items (Add, Update, Delete)
- Manage customer orders
- Update order status
- Dashboard for restaurant operations

Backend

Database

- PostgreSQL

---

Architecture

- React frontend communicates with the Spring Boot REST API.
- Spring Security secures endpoints
- JPA/Hibernate manages database operations with PostgreSQL.
- RESTful APIs handle user authentication, menu management, and order processing.
